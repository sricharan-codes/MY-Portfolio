# Sricharan Codes — Personal Portfolio

A fast, responsive, multi-page developer portfolio built with modern HTML5 and Tailwind CSS. Showcases engineering projects, technical milestones, systems philosophy, and personal interests.

---

## 🚀 Live Pages

* **Home (`index.html`)**: Introduction, core technical skill set (Python, HTML, CSS, Bootstrap), and direct contact portal.
* **Projects (`project.html`)**: Showcase of technical projects including terminal tools, frontend clones, and responsive landing pages.
* **Hobbies (`hobbies.html`)**: Editorial bento-grid highlighting gym & strength training, strategic anime analysis, tech discussions, and coding experiments.
* **Experience (`experience.html`)**: Career timeline featuring open-source contributions (such as GSSoC'26) and future engineering roadmap.
* **About Me (`about.html`)**: Detailed background on systems-first engineering philosophy, core competencies, and academic track.

---

## 🛠️ Built With

* **Markup & Structure**: HTML5 Semantic Elements
* **Styling**: [Tailwind CSS CDN](https://tailwindcss.com/)
* **Typography**:
  * Headings: [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans)
  * Body: [Inter](https://fonts.google.com/specimen/Inter)
  * Accents / Monospace: [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)
* **Icons**: [Font Awesome 6](https://fontawesome.com/)
